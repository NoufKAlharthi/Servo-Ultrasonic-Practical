 Servo Ultrasonic Practical

 Overview

An Arduino-based project that integrates an HC-SR04 ultrasonic sensor with an SG90 servo motor for distance-based control.

When an object is detected within **10 cm**, the servo rotates to **90°**. Otherwise, it remains at **0°**.
 
 Components

- Arduino Uno
- HC-SR04 Ultrasonic Sensor
- SG90 Servo Motor

 Technologies

Arduino • C++ • Embedded Systems • Sensor Integration
